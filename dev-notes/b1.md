# B1 notes moved

The ChurchApps B1 work — notes, house style, the design CSS, the compose file,
the nginx vhosts and the MTZ-B → B1 importer — now lives in its own repo:

**https://github.com/tbrooke/mtz-b1** (private)

It was split across this repo and an untracked directory on `trust`, and the
copy of the design that lived here had drifted 27 lines behind the database
that actually renders it. `mtz-b1/styles/sync.sh` is what keeps those two
honest now.

What stayed here: nothing B1-specific. The importer reads this project's SQLite
database (`storage/sqlite/main.db`) but is a B1 concern, so it lives there.
